О приложении

StepTrack Cloud — платформа для отслеживания активности. Данные синхронизируются через облако.

Как участвовать

  • Введите количество пройденных шагов
  • Прикрепите скриншот из приложения-трекера
  • Отправьте отчёт на проверку
  • После одобрения шаги попадут в рейтинг

Правила

Принимаются только настоящие скриншоты с вашего устройства. Подделка данных ведёт к блокировке аккаунта.
